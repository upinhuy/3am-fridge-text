[The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d)
bounty on [make.fun](https://make.fun).

## The line

> 3am. You've opened me 6 times tonight and taken nothing. We're not hungry, we're lonely — and I'm the only one here who'll say it.

## How it works

`main.ts` (Node 22, no dependencies) writes that single line to
`/output/entry.txt` — 130 characters, one line, UTF-8. Run it with:

```sh
node main.ts
```
